# Calculator Widget for Odoo

## Overview

A powerful floating calculator accessible from the systray, designed for quick calculations without leaving your current work in Odoo.

## 🚀 Features

- ✅ **Basic Arithmetic** - Addition, Subtraction, Multiplication, Division
- ✅ **Percentage Calculations** - Quick percentage operations
- ✅ **Memory Functions** - MC, MR, M+, M- for storing values
- ✅ **Calculation History** - Review your previous calculations
- ✅ **Copy to Clipboard** - Easily copy results
- ✅ **Keyboard Support** - Full keyboard navigation
- ✅ **Draggable Window** - Position the calculator anywhere on screen
- ✅ **Dark/Light Theme** - Adapts to your Odoo theme

## 📦 Installation

1. Download the module from Odoo Apps Store
2. Place the module in your Odoo addons directory
3. Update the apps list: `Settings > Apps > Update Apps List`
4. Search for "Calculator Widget" and click Install

## 📱 How to Use

1. Click the calculator icon in the systray (top right corner)
2. Perform calculations using buttons or keyboard
3. Use memory functions to store intermediate results
4. View calculation history by clicking the history icon
5. Copy results to clipboard with one click

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `0-9` | Input numbers |
| `+`, `-`, `*`, `/` | Operators |
| `Enter` | Calculate result |
| `Escape` | Clear/Close |
| `Backspace` | Delete last digit |
| `.` | Decimal point |
| `%` | Percentage |
